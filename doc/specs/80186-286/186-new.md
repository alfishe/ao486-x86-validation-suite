# Spec: 80186 New Instructions

## Metadata
- **Source file:** `src/cpu/80186/new.asm`
- **TIER:** UNIVERSAL | VENUE: G+H | GEN: 80186+ | ORACLE: manual
- **Impl-plan:** Phase 4, area `186`
- **Coverage:** [§5](../../coverage-matrix.md#5-cpu--80186-pri-3-thin-layer)
- **Divergences:** [prep-analysis §1.1](../../prep-analysis.md#11-instruction-availability-divergences)

## Purpose

Verify PUSHA/POPA, PUSH imm, INS/OUTS, BOUND, ENTER/LEAVE.
These are new in 80186+; must #UD or be absent on 8086.

## Test Cases

### PUSHA / POPA (all general registers)

| # | Action | Stack layout | Notes |
|---|--------|-------------|-------|
| 1 | PUSHA | AX,CX,DX,BX,original SP,BP,SI,DI | pushes 8 regs = 16 bytes |
| 2 | POPA | restores DI..AX, skips SP | original SP value is discarded |

> PUSHA pushes SP as it was BEFORE the push.
> POPA pops into DI,SI,BP,skips SP(discarded),BX,DX,CX,AX.

### PUSH imm16 (immediate push)

| # | Instruction | Expected [SP] | Notes |
|---|-------------|---------------|-------|
| 1 | PUSH 0x1234 | 0x1234 | |
| 2 | PUSH 0xFFFF | 0xFFFF | |
| 3 | PUSH byte_imm (sign-extended) | 0xFF00 for 0x00 | byte form sign-extends |

### INS / OUTS (I/O string)

| # | Instruction | Direction | Notes |
|---|-------------|-----------|-------|
| 1 | INSByte (INSB) | DX→[ES:DI], DI±1 | reads port DX |
| 2 | INSW | DX→[ES:DI], DI±2 | |
| 3 | OUTSB | [DS:SI]→DX port, SI±1 | |
| 4 | OUTSW | [DS:SI]→DX port, SI±2 | |

> I/O string ops require HARDWARE tier (touch ports). Use a safe port range.

### BOUND (array bounds check)

| # | Array index | Bounds (mem: lower, upper) | Expected | Notes |
|---|-------------|---------------------------|----------|-------|
| 1 | 5 | [0, 10] | no exception | 0 ≤ 5 ≤ 10 |
| 2 | 11 | [0, 10] | **#BR** | 11 > upper bound |
| 3 | -1 | [0, 10] | **#BR** | -1 < lower bound |

> BOUND checks: lower ≤ index ≤ upper. Violation → #BR (bound range exceeded).

### ENTER / LEAVE (stack frame)

| # | Action | Stack effect | Notes |
|---|--------|-------------|-------|
| 1 | ENTER 8, 0 | push BP; BP=SP; SP-=8 | simple frame, nesting=0 |
| 2 | ENTER 8, 1 | push BP + display; BP=SP; SP-=8 | nesting=1: copies 1 extra word |
| 3 | LEAVE | SP=BP; pop BP | restores frame |

> ENTER with nesting level N creates N-1 display entries (for scope chains).
> Max nesting level = 31 (bits 0-4 of imm8).

## Pre/Post State (representative cases)

### PUSHA — stack layout

```
PRE:
  AX=0x1111 CX=0x2222 DX=0x3333 BX=0x4444
  SP=0x0FFC BP=0x5555 SI=0x6666 DI=0x7777

  OP:  PUSHA

POST:
  SP=0x0FEC                    ← SP -= 16 (8 regs × 2 bytes)
  [SS:0x0FEC] = 0x1111          ← AX
  [SS:0x0FEE] = 0x2222          ← CX
  [SS:0x0FF0] = 0x3333          ← DX
  [SS:0x0FF2] = 0x4444          ← BX
  [SS:0x0FF4] = 0x0FFC          ← original SP (BEFORE PUSHA)
  [SS:0x0FF6] = 0x5555          ← BP
  [SS:0x0FF8] = 0x6666          ← SI
  [SS:0x0FFA] = 0x7777          ← DI
  Registers unchanged
```

### POPA — restore (SP discarded)

```
PRE:
  SP=0x0FEC (stack as left by PUSHA above)
  AX=0x???? DI=0x????

  OP:  POPA

POST:
  DI=0x7777 SI=0x6666 BP=0x5555
  (SP is loaded then discarded — SP remains 0x0FFC not 0x0FFC from stack)
  BX=0x4444 DX=0x3333 CX=0x2222 AX=0x1111
  SP=0x0FFC                    ← SP += 16 (but SP value from stack was discarded)
```

### PUSH imm16 vs PUSH imm8 (sign-extended)

```
PRE:
  SP=0x0FFC

  OP:  PUSH 0x1234              (opcode 68, imm16)
POST:
  SP=0x0FFA
  [SS:0x0FFA] = 0x1234

PRE:
  SP=0x0FFC
  OP:  PUSH byte 0x80           (opcode 6A, sign-extended imm8)
POST:
  SP=0x0FFA
  [SS:0x0FFA] = 0xFF80          ← sign-extended to 16-bit
```

### ENTER 8, 0 — simple frame

```
PRE:
  BP=0x1000
  SP=0x0FFC

  OP:  ENTER 8, 0

POST:
  SP=0x0FF0                    ← SP -= 2 (push BP) - 8 (alloc locals)
  [SS:0x0FFA] = 0x1000         ← old BP pushed
  BP=0x0FFA                    ← BP = new frame pointer
  Locals: [SS:0x0FF2..0x0FF9] = 8 bytes of uninitialized space
```

### LEAVE — restore frame

```
PRE:
  BP=0x0FFA
  SP=0x0FF2
  [SS:0x0FFA] = 0x1000         ← saved old BP

  OP:  LEAVE

POST:
  SP=0x0FFC                    ← SP = BP + 2 (restored past frame)
  BP=0x1000                    ← restored from stack
```

### BOUND — in-range (no exception)

```
PRE:
  AX = 0x0005                  (array index = 5)
  [DS:0x1000] = 0x0000         (lower bound)
  [DS:0x1002] = 0x000A         (upper bound = 10)

  OP:  BOUND AX, [0x1000]

POST:
  No exception (0 ≤ 5 ≤ 10)
  AX unchanged
```

### BOUND — out-of-range (#BR)

```
PRE:
  AX = 0x000B                  (index = 11)
  [DS:0x1000] = 0x0000         (lower = 0)
  [DS:0x1002] = 0x000A         (upper = 10)

  OP:  BOUND AX, [0x1000]

POST:
  #BR exception (INT 5)
  Return address pushed on stack
```

## State Save/Restore

- **Save:** all GPRs, SP, BP, FLAGS, DF, ES, DS
- **Restore:** `RESTORE_STATE`

## Pass/Fail Criteria

- **PASS:** all instructions execute correctly; #BR on BOUND violation
- **SKIP:** GEN < 80186 (all these instructions #UD or are absent on 8086)
