# Spec: A20 Gate & 1MB Address Wrap

## Metadata
- **Source file:** `src/core/a20.asm`
- **TIER:** HARDWARE | VENUE: G | GEN: 8086+ | ORACLE: manual
- **Impl-plan:** Phase 8, area `A20`
- **Coverage:** [§10, §10.1](../../coverage-matrix.md#101-hard-cases--a20--address-space)
- **Detail:** [prep-analysis §6](../../prep-analysis.md#6-peripheral-stateful-behavior)
- **Refs:** [references.md](../../references.md) — IBM AT Tech Ref; Intel 80286 PRM

## Purpose

Verify A20 gate behavior: when A20 is disabled, address bit 20 is forced to 0, causing
1MB wraparound. Test both enable paths (KBC output port, fast A20 via port 0x92) and
verify the wrap at `FFFF:0010`.

## Background

On the 8086, addresses wrap at 1MB (only 20 address lines). On the 286+, address line
A20 can be masked by the keyboard controller or the fast-A20 port, replicating the
8086 wrap for compatibility.

## Test Cases

### A20 wrap verification

| # | A20 state | Segment:offset | Physical addr | Expected read | Notes |
|---|:---------:|:--------------:|:-------------:|---------------|-------|
| 1 | OFF | FFFF:0010 | 0x100000 (A20=0 → 0x000000) | byte at 0000:0000 | wrap! |
| 2 | ON | FFFF:0010 | 0x100000 | byte at HMA (0x100000) | no wrap |
| 3 | OFF | FFFF:FFFF | 0x10FFEF (A20=0 → 0x0FFEF) | byte at 0x0FFEF | wrap |
| 4 | ON | FFFF:FFFF | 0x10FFEF | byte at 0x10FFEF | no wrap |

> **Test setup:** write a sentinel byte to 0000:0000 (e.g. 0xAA), write a different
> byte to the physical address via FFFF:0010+ (e.g. 0x55). Toggle A20 and verify
> which byte is read.

### Enable/disable via KBC (port 0x60/0x64)

| # | Action | Expected | Notes |
|---|--------|----------|-------|
| 1 | KBC: OUT 0x64, 0xD1 (write output port) | | |
| 2 | KBC: OUT 0x60, byte with bit 1=1 (A20 on) | A20 enabled | |
| 3 | KBC: OUT 0x64, 0xD1; OUT 0x60, byte with bit 1=0 | A20 disabled | |

> See [kbc.md](../peripheral/kbc.md) for KBC output port details.

### Enable/disable via fast A20 (port 0x92)

| # | Action | Expected | Notes |
|---|--------|----------|-------|
| 1 | Read 0x92 | bit 1 = current A20 state | system control port |
| 2 | OR 0x02 to 0x92 | A20 enabled | fast A20 gate |
| 3 | AND ~0x02 to 0x92 | A20 disabled | |

> **Warning:** port 0x92 bit 0 is the reset bit. Writing bit 0=1 causes immediate
> system reset. Always read-modify-write, never blind-write.

### Word/dword at segment-limit wrap (real mode)

| # | CPU gen | Operation | Expected | Notes |

### Stack wrap (SP=0xFFFE, PUSH)

| # | SP before | A20 | Operation | Expected | Notes |
|---|-----------|:---:|-----------|----------|-------|
| 1 | 0xFFFE | OFF | `push ax` | SP=0xFFFC, writes at FFFF:FFFE+FFFF:FFFF → wraps | |
| 2 | 0x0000 | OFF | `push ax` | SP=0xFFFE, wraps to FFFF:FFFE | 8086 wraps SP |

## Pre/Post State (representative cases)

### A20 OFF — wrap at FFFF:0010
PRE (real mode, A20 disabled):
  Memory at physical 0x000000 = 0xAA  (sentinel at IVT start)
  Memory at physical 0x100000 = 0x55  (sentinel in HMA; A20 off → masked)
  A20 gate = OFF (bit 20 forced to 0)
  DS = 0xFFFF, SI = 0x0010
OP:  MOV AL, [DS:SI]    ; linear addr = 0xFFFF*16 + 0x0010 = 0x100010
POST:
  AL = 0xAA            ← A20 masked: 0x100010 → 0x000010 → reads IVT area
  ← Physical address bit 20 = 0: 0x100010 becomes 0x000010

### A20 ON — no wrap
PRE (real mode, A20 enabled):
  Memory at physical 0x000000 = 0xAA
  Memory at physical 0x100000 = 0x55
  A20 gate = ON (bit 20 passes through)
  DS = 0xFFFF, SI = 0x0010
OP:  MOV AL, [DS:SI]    ; linear addr = 0x100010
POST:
  AL = 0x55            ← A20 enabled: 0x100010 reads from HMA (no wrap)

### Enable A20 via fast port 0x92
PRE:
  Port 0x92 = 0x00    (bit 1 = 0 → A20 disabled)
  A20 gate = OFF
OP:  IN  AL, 0x92      ; read current value (CRITICAL: must read first)
     OR  AL, 0x02      ; set bit 1 (A20 enable)
     OUT 0x92, AL      ; write back
POST:
  Port 0x92 = 0x02    (bit 1 = 1)
  A20 gate = ON
  ← WARNING: never blind-write 0x92; bit 0 is system reset!

### Enable A20 via KBC output port
PRE:
  KBC output port = 0xDD  (bit 1 = 0 → A20 disabled)
  A20 gate = OFF
OP:  OUT 0x64, 0xD0    ; read output port
     (poll OBF)
     IN  AL, 0x60      ; AL = 0xDD
     OR  AL, 0x02      ; set bit 1
     OUT 0x64, 0xD1    ; write output port command
     (poll IBF clear)
     OUT 0x60, AL      ; write 0xDF → A20 enabled
POST:
  KBC output port = 0xDF  (bit 1 = 1)
  A20 gate = ON

### A20 OFF — word access straddling boundary
PRE (8086 or 286+ with A20 off):
  DS = 0xFFFF
  Memory at 0x0FFFF = 0x11
  Memory at 0x10000 = 0x22 (HMA; A20 off → wraps to 0x00000)
  Memory at 0x00000 = 0xAA
OP:  MOV AX, [0xFFFF]  ; word at FFFF:FFFF = addr 0x10FFEF
POST:
  AX = 0xAA11         ← low byte from 0x0FFFF=0x11, high byte wraps to 0x00000=0xAA
  ← little-endian: [0x0FFFF]=0x11, [0x10000→0x00000]=0xAA

## State Save/Restore

- **Save:** A20 enable state (via KBC output port read 0xD0, or port 0x92 read)
- **Restore:** restore A20 to original state via whichever path was used
- **Memory:** restore the sentinel bytes at 0000:0000 and the test physical address

## Pass/Fail Criteria

- **PASS:** A20 off → wrap detected at FFFF:0010; A20 on → no wrap; both enable
  paths (KBC and fast A20) work
- **FAIL:** A20 toggle has no effect; wrap not detected; port 0x92 reset triggered
- **SKIP:** GEN < 80286 (8086 always wraps; no A20 gate)

## Known Divergences

- **Port 0x92 availability:** some systems don't implement fast A20 via 0x92.
  Detect by writing and verifying; fall back to KBC.
- **A20 timing:** there may be a delay between toggling and effect. Add a small
  delay or re-read after toggle.
- **8086:** always wraps (A20 always masked). This is the baseline.
