## Purpose

Verify V86 mode entry/exit, IOPL-sensitive instructions, #GP(0) trapping,
and the V86 monitor pattern (catching sensitive ops and emulating them).

## V86 Entry

V86 mode is entered by setting the VM bit (bit 17) in EFLAGS:
- Via IRET that loads a stack frame with VM=1
- Via task switch to a TSS with VM=1 in EFLAGS

```nasm
; Enter V86 via IRET:
; Push SS:ESP (ring 0 stack), EFLAGS (with VM=1), CS:IP (V86 code)
push dword DATA_SEL0   ; SS for V86 (real-mode style segment)
push dword V86_STACK   ; ESP for V86
pushfd
or dword [esp], EFLAG_VM  ; set VM bit
push dword 0x0000       ; CS (real-mode segment)
push dword V86_ENTRY    ; EIP
iretd                    ; enters V86 mode
```

## V86 Exit

V86 mode exits when:
- An IOPL-sensitive instruction triggers #GP(0)
- An interrupt/exception occurs (CPU switches to ring 0 handler)

## Test Cases

### V86 mode entry and detection

| # | Action | Expected | Notes |
|---|--------|----------|-------|
| 1 | IRET with VM=1 in EFLAGS | CPU enters V86 mode | segment regs become real-mode style |
| 2 | Read EFLAGS in V86 | VM=1 | can verify via PUSHFD in V86 handler |

### IOPL-sensitive instructions

| # | Instruction | IOPL | CPL | Expected | Notes |
|---|-------------|:----:|:---:|----------|-------|
| 1 | CLI | IOPL=3 | V86 | **#GP(0)** | blocked at IOPL=3 |
| 2 | CLI | IOPL=0 | V86 | OK (clears IF) | allowed at IOPL=0 |
| 3 | STI | IOPL=3 | V86 | **#GP(0)** | |
| 4 | PUSHF/POPF | IOPL=3 | V86 | **#GP(0)** | |
| 5 | INT n | IOPL=3 | V86 | **#GP(0)** (INT 3/INTO may differ) | |
| 6 | IRET | IOPL=3 | V86 | **#GP(0)** | |

> At IOPL=0, all sensitive instructions are allowed in V86.
> At IOPL=3, they all trap to the V86 monitor via #GP(0).
> At IOPL=1 or 2: CLI/STI/PUSHF/POPF trap; some others may not.

### IN/OUT in V86

| # | I/O permission | Port | IN/OUT | Expected | Notes |
|---|:--------------:|:----:|:------:|----------|-------|
| 1 | bitmap allows | 0x60 | IN | OK | |
| 2 | bitmap blocks | 0x60 | IN | **#GP(0)** | check I/O bitmap in TSS |

> I/O bitmap applies in V86 mode when IOPL < 3.

### Segment register loads in V86

| # | Action | Expected | Notes |
|---|--------|----------|-------|
| 1 | MOV AX, 0x1000; MOV DS, AX | DS base = 0x10000 | real-mode segment addressing |
| 2 | MOV ES, AX | ES base = sel × 16 | |

> In V86, segment registers use real-mode addressing (base = selector × 16),
> but the CPU is still in PM (page translation is active).

### V86 monitor pattern

The V86 monitor catches #GP(0) from sensitive instructions and emulates them:

```nasm
v86_gp_handler:
    ; Read faulting instruction from CS:EIP (V86 segment)
    ; Determine which sensitive instruction caused #GP
    ; Emulate it (e.g., simulate CLI by clearing VIF)
    ; Advance EIP past the instruction
    ; IRETD back to V86
```

| # | Sensitive instruction | Monitor action | Notes |
|---|----------------------|----------------|-------|
| 1 | CLI | set virtual IF=0 | emulate |
| 2 | STI | set virtual IF=1 | emulate |
| 3 | INT n | read interrupt vector from V86 IVT, emulate | IVT at linear 0 |

## Pre/Post State (representative cases)

### V86 entry via IRET
PRE (PM32, CPL=0):
  EFLAGS = 0x00000002  (VM=0, IF=0, real PM mode)
  Ring 0 stack frame (from top):
    [ESP+0x00] = V86_ENTRY   (target EIP in V86)
    [ESP+0x04] = 0x0000      (target CS — real-mode segment 0)
    [ESP+0x08] = 0x00020002  (EFLAGS with VM=1 bit17 set)
    [ESP+0x0C] = V86_STACK   (target ESP)
    [ESP+0x10] = 0x0000      (target SS — real-mode segment 0)
OP:  IRETD
POST:
  EIP  = V86_ENTRY
  CS   = 0x0000, base = 0x00000000  (real-mode style segment)
  SS   = 0x0000, base = 0x00000000
  ESP  = V86_STACK
  EFLAGS = 0x00020002  (VM=1, IF=1)
  CPL  = 3 effectively  (V86 runs at ring 3 privilege)

### Segment register load in V86 — real-mode addressing
PRE (V86 mode, VM=1):
  DS = 0x0000, base = 0x00000000
OP:  MOV AX, 0x1000
     MOV DS, AX
POST:
  DS = 0x1000, base = 0x00010000  ← base = selector × 16 (real-mode style)
  ← Paging is still active; DS:offset = linear 0x10000+offset

### IOPL=3: CLI in V86 → #GP(0)
PRE (V86 mode, IOPL=3):
  EFLAGS = 0x00030002  (VM=1, IOPL=3 bits12-13=11, IF=1)
  IF = 1
OP:  CLI                  (IOPL-sensitive in V86)
POST:
  #GP(0) exception       ← V86 monitor trap
  IF still = 1            ← CLI did not execute
  Monitor reads faulting opcode at CS:EIP → emulates CLI

### IOPL=0: CLI in V86 — OK
PRE (V86 mode, IOPL=0):
  EFLAGS = 0x00020002  (VM=1, IOPL=0, IF=1)
OP:  CLI
POST:
  no exception
  EFLAGS = 0x00020000  (IF=0 cleared)  ← IOPL=0 allows sensitive ops in V86

### INT n in V86 at IOPL=3 → #GP(0)
PRE (V86 mode, IOPL=3):
  EIP points to: INT 0x21
OP:  INT 0x21
POST:
  #GP(0) exception
  ← Monitor must read the INT opcode, fetch vector from IVT at linear 0,
    push V86 CS:IP:FLAGS, and IRETD to handler

### I/O bitmap blocks IN at CPL=3 in V86
PRE (V86 mode, IOPL=3):
  TSS I/O map base points to bitmap
  Bitmap bit for port 0x60 = 1  (blocked)
  DX = 0x0060
OP:  IN AL, DX            (read port 0x60)
POST:
  #GP(0) exception       ← I/O permission bitmap denies access

## State Save/Restore

- **Save:** EFLAGS (VM bit), IOPL, all segment regs
- **Restore:** exit V86, restore PM state

## Pass/Fail Criteria

- **PASS:** V86 entry/exit works; IOPL-sensitive ops trap correctly; monitor pattern works
- **FAIL:** no #GP(0) at IOPL=3, or wrong segment addressing in V86
- **SKIP:** GEN < 80386
